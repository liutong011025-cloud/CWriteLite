# Character and writing interface refinement — 4 October 2026

## Changes

- Character Studio guards generation and saving immediately with refs. One successful portrait is accepted automatically; the generate button disappears. A failed request can be retried. There is no portrait picker or acceptance button.
- New character saves use a stable creation key scoped to the signed-in user. Concurrent requests and retries return the same card, including Prisma's emulated-upsert race. Separately created student cards are retained, even when their names match.
- Adopting a pack character reuses an existing card, including a card with edited traits. Identical historical built-in cards display once without deleting student records. Cast selection and Canvas preparation remove duplicate aliases and unused cast nodes safely.
- The purple pack opens the user's shared deck in a same-page window. New character ideas are in a separate expandable section; saved ideas cannot be repeatedly adopted through the button.
- The character selection Cagent button now requests contextual help, shows its loading state, changes pose, presents the reply, and reports errors. Actual DeepSeek reply verified against Pip and Fox.
- Character detail has one header title, usage history, edit/delete controls and a single bottom Use in my story action.
- Canvas has no Add Character button. Object, setting, goal, note and connection controls are larger brown buttons. Examples remain beside the right-aligned zoom controls.
- The first Canvas entry automatically opens the bulb guide once per user. The account profile records the visit; a versioned, user-specific local marker handles immediate revisits. Manual opening remains available.
- Content sizing uses scoped typography, button, portrait and responsive-grid changes inside the existing Story/Drama frames. Writing text is 24px, prompts 21px, and rounded soft-color labels remain. No new raster assets or larger image downloads.

## Verification

- Concurrent new-character saves, same-key retry, separate same-name creation and concurrent pack adoption passed against the local API/database. Temporary test cards were removed. Results: `character-save-check-results.json`.
- Tested through the actual browser: first Canvas guide shown; returning after re-login did not show it; manual bulb opened normally; Add Character absent.
- Tested portrait flow in the existing local image-preview mode: generation immediately enables Save; acceptance and regeneration controls absent. Real Fal portrait generation was not tested; its prompt now explicitly requests one figure.
- Cagent help returned a real character-specific reply, rather than only animating the mascot.
- Character detail has exactly one My Character Card heading and no bottom Back to My Characters action. No horizontal overflow at the actual 1140px browser width.
- Character Studio's species buttons all fit inside the species panel after correcting intrinsic grid sizing. Story writing, Canvas and Drama viewed with the enlarged content.
- Production webpack build and TypeScript checks passed.
